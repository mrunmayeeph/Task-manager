# Task Manager App (MERN Stack)

A fully responsive **Task Manager** web application built with the **MERN** stack (MongoDB, Express, React, Node.js). This app allows users to manage tasks efficiently with an intuitive interface: create, update, track tasks with due dates and priorities, assign tasks to multiple users, and monitor completion status.

---

## Features

- **User Authentication & Authorization**
  - Register/Login
  - Admin and Member roles
- **Task Management**
  - Create, update, and delete tasks
  - Assign tasks to one or multiple users
  - Set priority and due dates
  - Track task status: Pending, In Progress, Completed
  - Todo checklist within tasks
  - File attachments for tasks
- **User Management**
  - Admin can view all users
  - Track task counts for each user
- **Reports**
  - Export tasks and user-task data to Excel
- **Dashboard**
  - Overview of tasks per user
  - Task statistics: pending, in-progress, completed
- **Responsive UI**
  - Mobile-first design
---

## Tech Stack

- **Frontend:** React, React Router, Tailwind CSS, React Icons, Axios  
- **Backend:** Node.js, Express.js, MongoDB (Mongoose), JWT Authentication  
- **Other:** ExcelJS (for exporting reports), react-hot-toast, react-select
